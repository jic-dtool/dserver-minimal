# dserver-minimal

[![dtool](https://github.com/jic-dtool/dserver-minimal/blob/main/icons/22x22/dtool_logo.png?raw=True)](https://github.com/jic-dtool/dserver-minimal) [![PyPI](https://img.shields.io/pypi/v/dserver-minimal)](https://pypi.org/project/dserver-minimal/) [![tag](https://img.shields.io/github/v/tag/jic-dtool/dserver-minimal)](https://github.com/jic-dtool/dserver-minimal/tags)

*dserver-minimal* is a meta package that provides a minimal working dserver
installation consisting of the core component [dservercore](https://github.com/jic-dtool/dservercore),
together with MongoDB-based search and retrieve plugin implementations
[dserver-search-plugin-mongo](https://github.com/jic-dtool/dserver-search-plugin-mongo) and
[dserver-retrieve-plugin-mongo](https://github.com/jic-dtool/dserver-retrieve-plugin-mongo).

Install from PyPI with

    pip install dserver-minimal

or directly from the `main` branch with

    pip install git+https://github.com/jic-dtool/dserver-minimal

and follow the general [configuration instructions](https://dservercore.readthedocs.io/en/latest/readme.html#setup-and-configuration) otherwise.
